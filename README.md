# Arte Interativa: Universo de Partículas

## Sobre o projeto
Este projeto utiliza p5.js para criar uma obra visual interativa. Ao mover o mouse pela tela, o usuário cria partículas coloridas que se conectam umas às outras.

## Como interagir
- Mova o mouse para criar partículas.
- Clique na tela para mudar a paleta de cores.
- Pressione `C` para limpar a tela.
- Pressione `S` para salvar a arte como imagem.

## Tecnologias
- HTML
- CSS
- JavaScript
- p5.js

## Como executar
Abra o arquivo `index.html` em um navegador com acesso à internet. A biblioteca p5.js é carregada pela internet.

## Conceitos de lógica de programação
- Variáveis e constantes.
- Listas (arrays).
- Repetição com `for`.
- Condições (`if`).
- Funções.
- Eventos de mouse e teclado.

## Objetivo de aprendizagem
Explorar como a lógica de programação pode transformar interações simples em uma experiência artística digital.
